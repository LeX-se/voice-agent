# Локальный голосовой агент «Voice Agent»

Программа для Windows 10, которая понимает русскую речь и текст, отвечает на вопросы
с помощью локальной модели (Ollama) и озвучивает ответы голосом IVONA 2 Maxim.
**Всё работает на вашем компьютере, без интернета и облаков.**

---

## Быстрый старт (для пользователя без навыков программирования)

1. **Дважды щёлкните по файлу `install.bat`.** Дождитесь надписи
   «Installation completed successfully!» и нажмите любую клавишу.
   Это нужно сделать только один раз.
   (Текст в окнах `install.bat` и `start.bat` на английском — так он гарантированно
   отображается корректно в любой кодировке консоли Windows. Само приложение
   работает полностью по-русски.)
2. **Дважды щёлкните по файлу `start.bat`.** Откроется окно с программой.

Перед первым запуском убедитесь, что:
- установлена [Ollama](https://ollama.com) и скачана модель командой
  `ollama pull qwen2.5:3b` (выполняется в обычном окне командной строки);
- установлен голос **IVONA 2 Maxim** (иначе будет использован другой доступный голос);
- компьютер видит микрофон и колонки.

## Как задавать вопросы

- **Текстом:** напечатайте вопрос в окне программы и нажмите Enter.
- **Голосом:** просто нажмите Enter (пустую строку) или наберите `/voice`,
  затем скажите фразу в микрофон и сделайте паузу — запись завершится автоматически.

Программа найдёт ответы в ваших заметках, спросит локальную модель, напечатает ответ
и прочитает его вслух.

## Как добавлять свои документы

1. Положите текстовые файлы (`.txt`, `.md`) в папку `knowledge`.
2. При следующем запуске пустая база проиндексируется автоматически,
   либо выполните команду `/reindex` (полная пересборка) или
   `/index knowledge` / `/file "C:\мои заметки\запись.txt"` (добавить конкретное).
3. Для заметок прямо из программы: `/add Проект называется локальный ассистент`.

Поддерживаются файлы UTF-8 не больше 10 МБ.

## Команды

| Команда | Что делает |
|---|---|
| `/help` | Список команд |
| `/status` | Состояние всех компонентов (Ollama, модель, Vosk, микрофон, голос) |
| `/voices` | Показать все голоса, доступные в Windows |
| `/say Проверка голоса` | Произнести указанный текст |
| `/voice` | Записать вопрос с микрофона |
| `/index <папка>` | Проиндексировать все подходящие файлы в папке (путь можно в кавычках) |
| `/file <файл>` | Добавить в базу знаний один файл |
| `/reindex` | Очистить базу знаний и заново проиндексировать `knowledge` |
| `/add <текст>` | Сохранить ручную заметку |
| `/history` или `/history 5` | Показать последние записи диалога |
| `/exit`, `/quit`, `выход` | Выйти из программы |

Любая строка, начинающаяся со `/` — команда, она не отправляется модели.

## Где что лежит

- История диалогов: `data\voice_agent.db` (файл базы SQLite).
- Журнал ошибок и технических событий: `logs\app.log`.
- Ваши документы для поиска: папка `knowledge`.
- Модель распознавания речи: `models\vosk-model-small-ru-0.22` (распакуйте туда
  архив `vosk-model-small-ru-0.22.zip` с сайта https://alphacephei.com/vosk/models).

Приватность: программа обращается только к локальному Ollama
(`http://localhost:11434`). Никакие данные никуда не отправляются.

## Проверка работоспособности (диагностика)

Если `install.bat` или `start.bat` завершаются с ошибкой — дважды щёлкните
**`check.bat`**. Он по шагам проверит:

1. наличие всех файлов проекта;
2. Python и виртуальное окружение `.venv`;
3. установку пакетов (requests, sounddevice, numpy, vosk, pyttsx3);
4. микрофон — список устройств записи;
5. модель Vosk в папке `models\`;
6. запущен ли Ollama на `http://localhost:11434` и какие модели установлены;
7. доступные голоса Windows для озвучки;
8. импорты самого приложения (без запуска основного цикла);
9. последние ошибки из `logs\app.log`.

В конце выводится итог: OK / FAILED с указанием, что именно починить. Полный отчёт
автоматически сохраняется в файл `data\check_report.txt` — его можно переслать тому,
кто помогает с настройкой. Текст диагностики на английском (надёжнее в консоли
Windows), само приложение полностью русское.

## Если что-то не работает

- **start.bat открывает окно и через 1–2 секунды закрывается, ничего не видно.**
  В текущей версии такое не должно происходить (окно ждёт нажатия клавиши). Если
  проблема осталась:
  1. запустите **check.bat** — он найдёт причину и сохранит отчёт в `data\check_report.txt`;
  2. откройте в проводнике папку проекта, в адресной строке наберите `cmd`, Enter,
     затем выполните: `".venv\Scripts\python.exe" -X utf8 app\main.py` — текст ошибки
     будет напечатан прямо в окне;
  3. посмотрите последние строки файла `logs\app.log`.
- **Не слышно ответов.** Выполните `/voices`: если список пуст или выбран нерусский
  голос, установите/активируйте IVONA 2 Maxim в системе. Программа продолжит работать
  без озвучки.
- **Микрофон молчит («Речь не обнаружена»).** Проверьте:
  «Параметры → Конфиденциальность → Микрофон» — доступ для настольных приложений
  должен быть разрешён. Убедитесь, что микрофон выбран в системе по умолчанию.
- **Ollama не отвечает.** Откройте отдельное окно командной строки и выполните
  `ollama serve` (или перезапустите приложение Ollama). Затем `/status`.
- **Модель не найдена.** Выполните `ollama pull qwen2.5:3b`.
- **Нет модели Vosk.** Скачайте `vosk-model-small-ru-0.22.zip` со страницы
  https://alphacephei.com/vosk/models и распакуйте в папку `models` так, чтобы
  получилась папка `models\vosk-model-small-ru-0.22`. Без неё работает текстовый ввод.
- **Ошибки при установке.** Запустите `install.bat` ещё раз; текст ошибок остаётся
  в окне до нажатия клавиши. Технические подробности — в `logs\app.log`.

├── knowledge/      # ваши текстовые заметки и документы

├── data/           # база данных (создаётся программой)

├── requirements.txt

├── start.bat       # шаг 2: запуск
├── check.bat       # диагностика: что именно не работает
