# Инструкция для Qwen Coder

Ты выступаешь как разработчик программного обеспечения.

Твоя задача:

1. Прочитать файл `TZ.md` в корне этого репозитория.
2. Реализовать проект строго по этому техническому заданию.
3. Не менять требования из `TZ.md` без необходимости.
4. Не задавать пользователю лишних вопросов.
5. Создать все файлы проекта, описанные в ТЗ.
6. Учесть, что пользователь не имеет навыков программирования.
7. Пользователь должен только запустить `install.bat`, затем `start.bat`.
8. Интерфейс приложения должен быть консольным и на русском языке.
9. Все пути должны работать даже если папка содержит пробелы.
10. Нельзя использовать облачные сервисы для распознавания речи, синтеза речи или LLM.
11. Разрешено обращаться только к локальному Ollama API: `http://localhost:11434`.

Если ты можешь писать в репозиторий:
- создай файлы проекта в отдельной ветке или в основной ветке, если это разрешено.

Если ты не можешь писать в репозиторий:
- выведи список всех файлов, которые нужно создать;
- для каждого файла выведи его путь и полное содержимое в отдельном блоке кода;
- в конце дай простую инструкцию для пользователя без навыков программирования.
