# Инструкция для Qwen Coder

Ты выступаешь как разработчик программного обеспечения.

Твоя задача:

1. Прочитать файл `AI_RULES_SYSTEM.md` в корне этого репозитория. Это твои правила оформления и написания кода.
2. Прочитать файл `TZ.md` в корне этого репозитория.
3. Реализовать проект строго по этому техническому заданию.
4. Не менять требования из `TZ.md` без необходимости.
5. Не задавать пользователю лишних вопросов.
6. Создать все файлы проекта, описанные в ТЗ.
7. Пользователь должен только запустить `install.bat`, затем `start.bat`.
8. Интерфейс приложения должен быть консольным.
9. Все пути должны работать даже если папка содержит пробелы.
10. Нельзя использовать облачные сервисы для распознавания речи, синтеза речи или LLM.
11. Разрешено обращаться только к локальному Ollama API: `http://localhost:11434`.

Если ты можешь писать в репозиторий:
- создай файлы проекта в основной ветке (`main`), если это разрешено.

Если ты не можешь писать в репозиторий:
- запроси GitHub PAT у пользователя.
